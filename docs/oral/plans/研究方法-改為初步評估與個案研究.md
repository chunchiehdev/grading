> **老師指導意見：** 本研究其實不是混合研究（mixed methods），而是
> （1）系統開發後的**初步評估／初探研究**

## 一、為什麼老師說得對

正式的「混合方法研究（Mixed Methods Research, Creswell）」必須具備：

1. **明確的整合策略**：convergent / explanatory sequential / exploratory sequential / embedded 其中之一
2. **正式的質性編碼或主題分析**，且與量化結果做 joint display（聯合呈現）或三角檢證
3. 寫出 **mixing rationale**（為什麼非混不可的理論理由）

**本研究實際只有：**

- TAM 量化問卷（RQ1、RQ2）
- 功能有用性量表（量化）
- AI 分項評分（量化敘述 + 推論統計）
- 學生開放題引述（沒有正式編碼）
- 對話紀錄（沒有正式編碼）

**沒有任何正式的質性編碼分析**，所以宣稱「混合方法」是過度宣稱。
老師建議改為 **初步評估 + 個案研究** 才是準確的方法論定位。

## 二、Yin (2018) 是什麼？

### 完整書目（APA 7）

> Yin, R. K. (2018). *Case study research and applications: Design and methods* (6th ed.). SAGE Publications.

### 為什麼引用這本？

**Robert K. Yin** 是個案研究方法學的權威，這本書是個案研究領域**最廣泛被引用的方法論經典**（被引超過 11 萬次）。

### Yin 對個案研究的核心定義

> 「個案研究是一種對**當代現象**（contemporary phenomenon）於其**真實世界脈絡**（real-life context）中進行**深度探討**的實證研究，特別適用於現象與脈絡之間的界線並不明顯之情況。」

### 為什麼你的研究適合「個案研究」框架？

| Yin 對個案研究的特徵 | 你的研究符合之處 |
|---|---|
| 研究**當代現象** | LLM 反思回饋系統屬於新興教育科技 |
| 在**真實脈絡**中進行 | 直接在研究所兩門課程的真實課堂中部署 |
| **無法控制變項** | 你不能隨機分組、不能設對照組 |
| **「如何」「為何」類型問題** | 你問「學生於系統使用歷程中呈現什麼反思特徵」 |
| **小樣本深度** | 28 位學生、110 份作業、17 位完成 ≥3 次提交 |
| **多元資料來源** | TAM 問卷 + 功能評價 + AI 評分 + 對話紀錄 + 採納決策 |

### Yin 的個案研究類型

Yin 區分四種設計：

1. **Single-case holistic**（單一個案、整體分析）
2. **Single-case embedded**（單一個案、嵌入多單元分析）
3. **Multiple-case holistic**（多個案、整體分析）
4. **Multiple-case embedded**（多個案、嵌入多單元分析）

**你的研究最接近 ②「Single-case embedded」**：
- 個案 = 「LLM 反思回饋系統於研究所課程中的初步部署」
- 嵌入單元 = 28 位學生個別的提交歷程

或可主張為 ③「Multiple-case」：兩門課程視為兩個個案。
**口試時建議用「個案研究情境」這種較彈性的措辭**，避免被追問為何不嚴格做跨個案比較。
