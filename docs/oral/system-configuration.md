## 四、系統服務部署配置

| 項目 | 說明 |
| --- | --- |
| gradsystem | 主系統服務，部署 3 個副本，提供課程管理、作業提交、AI回饋與評量功能 |
| websocket | 即時互動服務，部署 3 個副本，提供即時訊息或事件互動支援 |
| postgres | 資料庫服務，部署 1 個副本，儲存課程、作業、提交與評量資料 |
| redis | 快取與工作佇列服務，部署 1 個副本，支援快取與背景工作處理 |
| minio | 檔案儲存服務，部署 1 個副本，儲存上傳檔案與相關文件 |
| traefik | Ingress 服務，負責外部流量導入與路由分派 |

## 五、使用環境建議

建議使用者以 Google Chrome、Mozilla Firefox 或 Microsoft Edge 等現代瀏覽器使用本系統，以獲得較佳之介面顯示與互動操作體驗。
